
  # Review Web Design Prototype

  This is a code bundle for Review Web Design Prototype. The original project is available at https://www.figma.com/design/8uaTPqK4RyECdJxFYTTP32/Review-Web-Design-Prototype.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Environment

  Copy `frontend/.env.example` to `frontend/.env` before deploying.
Set `VITE_API_URL` to your backend URL, for example:

```env
VITE_API_URL=https://udaiapi.datamoshtechnologies.com/api
VITE_ADMIN_API_BASE=https://udaiapi.datamoshtechnologies.com/api/admin
VITE_SITE_URL=https://udairehab.org
VITE_ADMIN_URL=https://admin.udairehab.org
VITE_RAZORPAY_KEY_ID=rzp_test_your_key_id
```
